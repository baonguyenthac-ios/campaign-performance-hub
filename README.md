# Campaign Performance Hub

Thiết kế lại trang Performance Campaign cho ứng dụng Influencer Marketing. Hiển thị tổng quan chiến dịch gồm số booking, tỷ lệ hoàn thành, giao đúng hạn, duyệt lần đầu, điểm đánh giá, chi phí đã thanh toán; thống kê nội dung bàn giao/đã đăng/lượt chỉnh sửa; và bảng hiệu suất từng Creator. Thể hiện rõ trạng thái dữ liệu, cảnh báo chất lượng và hỗ trợ loading, empty, error. Giao diện hiện đại, dễ so sánh, responsive trên mobile, tablet, desktop
